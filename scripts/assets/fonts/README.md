# Social preview fonts

Vendored fonts keep builds independent of system fonts and font CDNs.

- Inter Regular/Bold: [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), `extras/ttf/`. License: `Inter-LICENSE.txt` (SIL Open Font License 1.1).
- Noto Sans JP Regular/Bold: [Noto CJK Japanese subset fonts](https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/JP). License: `NotoSansJP-OFL.txt` (SIL Open Font License 1.1).

Published SVG text becomes paths. Font files remain build inputs and are not served.
